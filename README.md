## 三个机房的线路差在哪

### 洛杉矶：电信联通去程 GIA，移动去程 CMI

Pro 系列的去程，电信和联通走 CN2 GIA，移动走 CMI（香港移动 AS58453）；回程三网全部 CN2 GIA，IPv6 走 CMIN2 优化线路。全系 KVM 虚拟化、AMD EPYC 处理器、企业级 SSD。公开测评里的 Geekbench 6 单核跑分 1728，跑建站、代理、轻量计算都够。

这里有个第三方说法值得知道：据公开测评，搬瓦工 DC6 机房的上游带宽就是从 DMIT 买的，DMIT 是带宽源头之一，不是转卖商。这不是 DMIT 官方声明，但能解释为什么两家的线路体感接近。

洛杉矶的测试 IP 是 `154.17.2.10`，下单前可以自己 ping 一下，比看任何测评都直接。

### 香港：延迟最低，代价是价格和流量

香港机房电信双向 CN2 GIA，移动和联通直连。公开测评显示国内访问平均延迟 39ms 左右，网络稳定、基本不丢包。

39ms 和洛杉矶的 160ms 是两个量级的体验差别。问题在于价格：MongKok 这档 1 核 1G，年付 $149.9，月流量只有 200GB，带宽 150Mbps。同样用途在洛杉矶，$36.9 就能拿到 500GB 月流量和 500Mbps 带宽。

### 东京：亚太业务的选择，带宽锁死 100Mbps

东京去程三网直连，电信 CN2 GIA、联通 AS9929、移动 CMI，三网回程 CN2 GIA，教育网回程也走 CN2 GIA。实测平台是 AMD EPYC 7402P，硬盘 IO 约 900MB/s。国内国外上传下载都能跑满 100Mbps，与官方标称一致。

东京全系带宽都是 100Mbps，这是它和洛杉矶最大的硬件差别。洛杉矶入门款是 500Mbps，往上到 4Gbps、5Gbps。要跑大流量分发，东京不合适。

## 晚高峰实测：延迟、丢包、超售

洛杉矶 Pro 的非高峰时段，国内三网平均延迟在 155–165ms。晚高峰实测没有明显飘移：电信 155–160ms，联通 160ms 出头，移动稍高但也在 165ms 以内。丢包率正常使用状态下基本在 0.1% 以下。

160ms 是美西到国内物理距离能跑出的正常水平，换任何商家都不会更低。要 50ms 以内，只能换机房，不是换商家能解决的问题。

东京的回程 traceroute 数据更能说明问题：上海移动 34.43ms、上海电信 58.38ms、厦门电信 72.13ms、广州电信 106.52ms、重庆联通 105.95ms、成都联通 104.56ms、成都教育网 108.82ms。这些是各地回程落地的关键跳延迟，不是三网平均值，但能看出江浙沪一带最优、西南和华南略高。丢包测试在中午 11 点和晚上 10 点各做一次，晚高峰到国内只有极少数线路丢包，白天丢包率极低。

不超售是这些数据能成立的前提。DMIT 控制单台物理机上的用户数，代价是热门套餐经常缺货，宁可少卖也不降服务质量。这也是为什么 MALIBU 这类限量款上架几小时就没了。

**只支持 Linux，不支持 Windows。** 需要 Windows 环境的直接排除。

**强制 SSH 密钥登录，不支持 root 密码。** 购买后要在后台下载密钥文件，再用 SSH 客户端连接。安全性更高，对没用过密钥登录的人有十来分钟的学习成本。

**新账号有 7 天等待期。** 注册完不能马上下单，急着用要提前几天把账号建好。这是最容易被忽略、又最耽误事的一条。

**IP 被墙可以换，但有规则。** 每 15 天免费换一次，其它情况 $5/次。

**流量超了不停机，只降速。** WEE 和 MALIBU 超量后限速 2Mbps，PalmSpring 及以上限速 4Mbps。2Mbps 基本只能跑文字和轻量 SSH，看视频就别想了，月初记得看用量。
